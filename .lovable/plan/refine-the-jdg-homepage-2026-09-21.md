# Refine the JDG Homepage

## Goal
Transform the existing JDG homepage into a premium fashion-house manifesto while preserving the current JDG navigation, catalogue, assets, and wider Uprising experience.

## Build
- Recompose the hero so the official emblem and “THE REBIRTH OF SELF” carry equal visual weight, retaining the supporting statement and collection link.
- Add a large emblem chapter immediately below the hero with restrained architectural line work and slow scroll reveals.
- Add five connected editorial passages for Identity, Rising, Vision, Structure, and Value without conventional cards.
- Add the “Becoming Who You Are Is Never Simple” journey statement with the emblem as a subtle visual anchor.
- Add the JDG / Uprising / Rebirth three-part manifesto and the final centered brand statement.
- Use near-black surfaces, off-white type, metallic-gold accents, strict grids, thin rules, and generous negative space.

## Motion and Accessibility
- Use restrained fade, line-drawing, illumination, and subtle emblem parallax effects.
- Respect reduced-motion preferences and keep all content readable without animation.
- Preserve responsive behavior on mobile and desktop.

## Verification
- Check the full JDG homepage at desktop and mobile sizes.
- Confirm the collection link and JDG navigation still work.
- Confirm the official emblem loads and no existing Uprising page is changed.
